Tyna Shield

Segurança que roda em toda mensagem, não é opcional

O Shield não é um filtro de saída. É uma camada que opera antes do envio ao modelo, de forma determinística e auditável.

PII

Mascaramento de dados pessoais

CPF, CNPJ, e-mail, cartão de crédito — detectados e mascarados por regex determinístico. Zero probabilidade de vazamento desses campos.

Segredos

Bloqueio de segredos e tokens

Chaves AWS, tokens GitHub e Slack, JWTs — se detectados, a mensagem inteira é bloqueada antes de qualquer envio externo.

Prompt Injection

Detecção de prompt injection

Heurística de alta velocidade + classificador sob demanda para ataques sofisticados. Proteção em duas camadas sem latência perceptível.

Shadow AI

Shadow AI Discovery

Detecta uso paralelo de ChatGPT, Gemini e Claude.ai pessoal. O administrador vê onde a política corporativa não está sendo seguida.

RAG

Fidelidade RAG anti-alucinação

Verifica se cada resposta é sustentada pelo contexto recuperado. Respostas sem suporte no corpus são sinalizadas antes de chegar ao usuário.

Compliance

Trilha de auditoria completa

Todo evento — mensagem, classificação, bloqueio, modelo usado — é registrado e exportável em CSV. Conformidade documentada por mensagem.

Painel do administrador

Controle total para o administrador

Multi-tenant desde o primeiro dia, com isolamento testado em produção. O administrador vê tudo, controla tudo, sem depender do time de TI para cada configuração.

Isolamento

Multi-tenant nativo

Row Level Security no Postgres — cada organização é isolada no banco. Testado em produção, não só documentado em papel.

Financeiro

Billing granular por organização

Tokens consumidos, custo em reais, modelo usado — por mensagem, por usuário, por organização. Billing explicável para qualquer cliente interno.

Acesso

RBAC sem autocadastro

Papéis admin, member e super-admin. Sem registro livre — cada usuário é adicionado pelo administrador da organização. Controle real de quem usa.

Automação

Agentes autônomos

Cron jobs e webhooks Slack e Chatwoot. O agente executa tarefas programadas ou disparadas por evento, com auditoria completa de cada execução.

Multi-provedor

Catálogo multi-provedor com preços editáveis

Anthropic Claude, OpenAI e Google Gemini num único catálogo. O administrador edita os preços exibidos para os times — útil para repassar custo com margem para clientes internos.

Por que a Tyna

Cinco razões pelas quais empresas escolhem a plataforma

Não são diferenciais de marketing. São decisões de arquitetura que têm consequência operacional e financeira.

Custo sob controle por arquitetura

A triagem automática Haiku → Sonnet → Opus garante que cada prompt paga exatamente o que vale. Não é um toggle — é o fluxo padrão. Sem essa lógica, 100% dos prompts pagam o preço do modelo mais caro.

Segurança embutida no fluxo

O Shield não é uma feature adicional nem um checkbox de compliance. Ele roda antes de cada envio externo, de forma silenciosa para o usuário. Não depende de treinamento — depende de arquitetura.

Multi-tenant pronto para vender

Mesma instância, múltiplos clientes, sem risco de vazamento cruzado. Row Level Security implementado e testado — não só prometido. Empresas que revendem IA para seus clientes usam a mesma infraestrutura.

Self-hosted na AWS

Os dados nunca saem do ambiente controlado pela Tyna. Nenhum dado de usuário trafega por infraestrutura não gerenciada. Para setores regulados, isso não é opção — é requisito.

Transparência operacional

Auditoria por mensagem, billing explicável, classificação visível para o administrador. Quando o time de compliance perguntar o que aconteceu com um dado, a resposta está no painel, não num ticket para o time de engenharia.
